# Photo by Perova

Публичный сайт: https://enpero.github.io/photoByPerova/

Основной репозиторий: https://github.com/enpero/photoByPerova
Все изменения сайта публикуются через этот репозиторий и GitHub Pages (ветка main, папка /docs).

## Текущий дизайн

Пустая страница без видимого текста, фотографий, кнопок и навигации. Нежно-голубой фон и прозрачная стеклянная панель. Адаптивная верстка, без JavaScript, внешних шрифтов и зависимостей.

## Обновление

Редактируйте `page.html`, выполните `npm run build:pages` и отправьте изменения, включая `docs/index.html`, в main. GitHub Pages опубликует обновление автоматически.

Предыдущая серверная реализация в `worker/` не используется GitHub Pages.

## Разделы и порядок

Вверху галереи доступны «Все фото», «Животные», «Природа», «Люди», «Буба». Одновременно выбран только один раздел. По умолчанию открыты «Все фото». Повторное нажатие на текущий раздел сохраняет выбор. Кот на первых шести снимках отмечен одновременно как «Животные» и «Буба». Портреты из карусели DfppvfLCIeO находятся в разделе «Люди». Для пустого раздела показывается сообщение. Архитектурный кадр без соответствующего тега доступен в «Все фото».

Теги хранятся в `docs/photos.json` и в `data-tags` соответствующих кадров в `page.html`. Кнопка «Перемешать» меняет порядок текущей выборки; просмотр альбома следует этому же порядку и учитывает выбранный раздел. Проверка: `npm run test:gallery`.
