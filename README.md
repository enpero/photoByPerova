# Photo by Perova

Публичный сайт: https://enpero.github.io/photoByPerova/

Основной репозиторий: https://github.com/enpero/photoByPerova
Все изменения сайта публикуются через этот репозиторий и GitHub Pages (ветка main, папка /docs).

## Текущий дизайн

Пустая страница без видимого текста, фотографий, кнопок и навигации. Нежно-голубой фон и прозрачная стеклянная панель. Адаптивная верстка, без JavaScript, внешних шрифтов и зависимостей.

## Обновление

Редактируйте `page.html`, выполните `npm run build:pages` и отправьте изменения, включая `docs/index.html`, в main. GitHub Pages опубликует обновление автоматически.

Предыдущая серверная реализация в `worker/` не используется GitHub Pages.

## Разделы и порядок

Вверху галереи доступны «Все фото», «Животные», «Природа», «Люди», «Буба». Одновременно выбран только один раздел. По умолчанию открыты «Все фото». Повторное нажатие на текущий раздел сохраняет выбор. Кот на первых шести снимках отмечен одновременно как «Животные» и «Буба». Портреты из карусели DfppvfLCIeO находятся в разделе «Люди». Для пустого раздела показывается сообщение. Архитектурный кадр без соответствующего тега доступен в «Все фото».

Теги хранятся в `docs/photos.json` и в `data-tags` соответствующих кадров в `page.html`. Фотографии автоматически перемешиваются при каждом открытии страницы. Кнопки «Перемешать» нет. Выбранный раздел сохраняет случайный порядок текущего открытия; просмотр альбома следует этому же порядку. Проверка: `npm run test:gallery`.

## Адаптивная версия

Телефоны до 768 px: кнопки разделов переносятся на следующие строки, обычная галерея в одну колонку, квадратная сетка в три. Планшеты 768–1023 px: две обычные колонки или четыре квадратные. Ноутбуки от 1024 px: три обычные колонки или шесть квадратных. Кнопки имеют область нажатия не меньше 44 px; просмотр учитывает safe area и горизонтальную ориентацию телефона. Метаданные и постоянный адрес сайта сохраняются.

## Ручное переключение версии

Кнопка под шапкой переключает мобильный и десктопный вид. До первого ручного выбора сайт адаптируется к ширине устройства. Мобильный вид на компьютере ограничен шириной 460 px; десктопный вид на телефоне использует виртуальную ширину 1100 px. Выбор сохраняется в localStorage (`perova-device-view`). Адаптивные стили используют container queries по ширине страницы, поэтому применяются и при ручном переключении. Проверка: `node scripts/test-device.cjs`.
