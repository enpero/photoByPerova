# Свет / Кадр
Одностраничное фотопортфолио на русском языке. Адаптивная галерея, категории, просмотр в модальном окне, загрузка JPEG/PNG/WebP и скачивание исходных файлов без перекодирования.

## Разработка
Node.js 20+; зависимости не нужны.

```sh
npm run build
npm test
```

`page.html` — интерфейс, `worker/index.js` — сервер Cloudflare Worker, `scripts/build.mjs` — сборка. R2 binding: `BUCKET`. Фотографии постоянно хранятся в R2, метаданные — в customMetadata объекта. Размер файла до 40 МБ, пакет до 10 файлов. Демопримеры с Unsplash исчезают из галереи после первой загрузки. Шрифты Google Fonts, с системным fallback.

## Доступ
Сайт создан с доступом только для владельца. Запись требует заголовок платформенной идентификации. **Перед открытием сайта другим посетителям добавьте проверку конкретного ID владельца на POST /api/photos**, чтобы право загрузки осталось только у фотографа. Не меняйте аудиторию без этой проверки. Для публикации широкой аудитории нужна отдельная настройка доступа Sites.

Исходные фотографии могут содержать EXIF, включая координаты: при необходимости удаляйте их перед загрузкой. Сервер сохраняет файл в точности как получен.

Автоматизированные проверки используют in-memory R2: проверяют авторизацию, отклонение неподходящих файлов и точное совпадение байтов скачанного оригинала. Интеграция с боевым R2 и визуальная проверка в браузере отдельно не выполнялись.

## GitHub Pages — публичный сайт из этого репозитория

Адрес: https://enpero.github.io/photoByPerova/

В Settings → Pages → Build and deployment выберите **Deploy from a branch**, ветку **main**, папку **/docs**, затем Save. Изменения в папке docs будут автоматически опубликованы GitHub.

Это отдельная статическая версия: сервер и R2 не требуются. Кнопка добавления открывает загрузку файлов в GitHub и требует ваших прав на репозиторий; посетители не могут добавлять работы. Поле `url` ниже — относительный путь к оригиналу, который и скачивается без сжатия.

### Добавление фотографий

1. Загрузите файлы в `docs/photos/` через Add file → Upload files (браузер GitHub: до 25 МБ на файл).
2. Отредактируйте `docs/photos.json`, добавив запись на каждый файл:

```json
[
  {
    "id": "mountains-01",
    "title": "Тишина гор",
    "category": "Природа",
    "url": "./photos/mountains.jpg",
    "size": 7340032
  }
]
```

`size` — размер в байтах. Категории: `Природа`, `Город`, `Люди`. Желательно использовать имена файлов латиницей без пробелов. Пока список пуст, сайт показывает примеры Unsplash. После коммита дождитесь обновления Pages.

Чтобы перенести изменения дизайна из `page.html` в Pages, запустите `npm run build:pages` и закоммитьте обновлённый `docs/index.html`. Файл `docs/photos.json` при сборке не перезаписывается.
