# Поисковая оптимизация Photo by Ekaterina Perova

Постоянный адрес: https://enpero.github.io/photoByPerova/
Карта сайта: https://enpero.github.io/photoByPerova/sitemap.xml

Настроены заголовок и описание для фотографий Кипра, природы и котов; видимый вводный текст, описания 68 фотографий, canonical и разрешение индексации. JSON-LD описывает автора, сайт и фотогалерею. Карта сайта содержит главную страницу и URL всех изображений. Фотографии других мест не выдаются за снимки Кипра. Условия использования опубликованы на rights.html: личное скачивание разрешено, публикация, коммерческое использование, продажа и редактирование требуют согласования. Метаданные каждого изображения содержат copyrightNotice, license и acquireLicensePage с реальными ссылками на эти условия.

## Следующий шаг: отправить сайт поисковикам

1. В Google Search Console добавьте ресурс с префиксом URL `https://enpero.github.io/photoByPerova/`.
2. Выберите подтверждение HTML-тегом. Передайте выданный Google meta-тег для добавления в head. Для варианта с HTML-файлом загрузите полученный файл в репозиторий — его нужно опубликовать в docs под исходным именем. Доступ к аккаунту и пароли не нужны.
3. После подтверждения отправьте `sitemap.xml` через раздел Sitemaps и запросите индексирование главной страницы через URL Inspection.
4. При необходимости добавьте сайт в Яндекс Вебмастер и подтвердите его отдельным выданным сервисом тегом или файлом.

Регистрация, подтверждение прав и отправка карты сайта в поисковые кабинеты пока не выполнены. Индексация и позиции не гарантированы; их следует проверять по данным поисковых кабинетов, а не по наличию метатегов.

## Обновления

Тексты фотографий хранятся в поле `title` файла docs/photos.json. При добавлении новых снимков задайте содержательные title и alt, затем выполните `npm run build:pages`. Сборка обновит JSON-LD и sitemap.xml автоматически. Не добавляйте отсутствующие на снимке предметы, неизвестные геолокации и повторяющиеся ключевые слова.

`robots.txt` должен находиться в корне домена `/robots.txt`. У сайта проекта GitHub Pages путь `/photoByPerova/robots.txt` не заменяет корневой файл; здесь не создаётся вводящий в заблуждение robots.txt. Отсутствие файла само по себе не запрещает индексацию.

Проверки: `npm run test:seo`, `npm run test:gallery`, `node scripts/test-device.cjs`.
